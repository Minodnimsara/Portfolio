Portfolio admin

Add or remove videos and screenshots. Changes go straight to your GitHub repository.

Connect to GitHub to start.

1. Connect

You only need to do this once per browser. Your key stays in this browser and is sent only to GitHub.

  1. Open GitHub → New fine-grained token.
  2. Set Expiration to the longest option, and Repository access to Only select repositories, then choose your portfolio repository.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Generate the token and paste it below.

2. Add a project video or image

Videos up to about 90 MB. Keep them short for fast loading.

3. Add client feedback screenshots

You can choose several images at once.
